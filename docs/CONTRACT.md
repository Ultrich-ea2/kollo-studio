# Kollo implementation contract

Student presentation studio with a reusable theme and flexible slide structure. German interface; three editable academic example decks explicitly marked as fictitious. The author has separately authorized publication of his original 6:32 DELFI demonstration, including its original credits and timed narration text. Other personal research and feedback are not published. The AI skill remains general and contains no DELFI-specific instructions or source materials. Repository source, offline kit and a general AI authoring/adaptation skill are in scope; Vercel hosting. The studio processes presentation content on device; users control any separate sharing with an AI service.

Shared model (src/model.ts): Deck {version:1,title:string,author:string,institution:string,date:string,duration:number,theme:{background:string,foreground:string,muted:string,primary:string,secondary:string,font:'Arial'|'Georgia',scale:number,showProgress:boolean},slides:Slide[]}. Slide {id:string,layout:'title'|'section'|'bullets'|'columns'|'process'|'stats'|'quote'|'code'|'image'|'chart'|'references'|'closing',section:string,title:string,subtitle:string,items:string[],body:string,image:string,imageAlt:string,notes:string,source:string,transition:'none'|'fade'|'slide'|'zoom',reveal:boolean,seconds:number}. All fields required. Images only embedded PNG/JPEG/WebP, no remote URLs or SVG. Items format: columns uses two strings; stats/chart use "value | label"; chart numeric nonnegative values.

Exports and UI share a deterministic scene at 1280x720. src/scene.ts exports createScene(slide,deck,index): Scene {background:string,elements:Element[],warnings:string[]}. Elements: Rect {type:'rect',x,y,w,h,fill,stroke?:string,radius?:number,group?:number}, Text {type:'text',x,y,w,h,text,fontSize,color,bold?:boolean,font?:string,align?:'left'|'center'|'right',group?:number}, Image {type:'image',x,y,w,h,src,alt,group?:number}. Text elements contain a single already-wrapped line. Font size pixels. Scene text top coordinates; shared export mapping must account for font baselines. createScene never drops content silently: warn on overflow. svgMarkup(scene): string escapes all text. Visible animations grouped by group integer.

src/model.ts exports defaultDeck (10-12 example slides), layouts Record<layout,string>, createSlide(layout), parseDeck(input:unknown): Deck throws clear German errors, validateDeck(deck): string[], templates Array<{id,name,description,deck}>, cloneDeck(deck):Deck. Import max file 10MB, <=80slides, bounded fields/items/data images, reject invalid schema/prototype keys, preserve valid input exactly (no silent truncation).

src/exports.ts exports async exportPptx(deck,mode:'editable'|'visual'):Promise<Blob>, exportPdf(deck):Promise<Blob>, exportHtml(deck):Promise<Blob>, exportKit(deck):Promise<Blob>, downloadBlob(blob,filename). No automatic download inside exports. Pure standalone HTML plays embedded slides with keyboard navigation/reveals, timer and notes; no network. Editable PPTX uses native scene shapes/text and speaker notes. Visual PPTX and PDF use high-resolution rendered scenes. Disclosure of animation fidelity per format. PPTX basic transition supported via safe OOXML patch if tested, browser-only effects clearly disclosed.

The optional theme.composition field accepts classic, editorial, technical or stage. Absence preserves the existing classic rendering and original JSON. The portable Python validator and browser validator share the same allowed values. New designs do not change the twelve layout names.

src/presenter/runtime.mjs is the common dependency-free player for the React studio and standalone HTML. The controller owns slide/reveal/time/blackout state and directly held child windows. Audience DOM excludes notes. Reading speed is an estimate, not speech recognition. A separate-window reload reconnects with a fresh window identity; a child navigated away is no longer owned. Popup opening requires a direct user action. No cross-device synchronization is offered.

Student distribution separates examples, skills, studio, source and guides, with a local START-HIER.html entry point. scripts/sync-skill-examples.ts generates portable skill examples from the authored src/examples.ts; scripts/build-examples.ts generates actual HTML/JSON/SVG/PPTX examples. scripts/package.mjs packages only curated project trees. Private QA material stays outside public source and archives. The offline editor is served only on loopback and does not include a recursive copy of its own distribution archive.

The authorized DELFI showcase is separate from the editable Kollo deck model and shared slide player. Its maintained source is under showcases/delfi: content, HTML template, CSS, JavaScript, original MP4, preview JPEG and provenance. Preserve the original media bytes, sixteen scene timings, speech text and credits to Ultrich Edima Edima and André Greubel. The video is 392 seconds long, 1920×1080, and has no audio track. It is a historical software demonstration dated 2026-09-08, not a new performance claim or an editable slide template.

The DELFI player uses video time to guide the teleprompter and synchronize a separate audience window. User speech is not recorded or recognized. The main controller owns its audience window; multiple independent controllers must not take over one another's windows. Preserve offline playback and do not make network requests to the linked software demo automatically. Hosted execution must work under the deployed CSP without relaxing script policy for the whole site.

Build output examples/delfi includes standalone presentation.html, hosted vorfuehren.html with separate assets, preview.jpg, GESTALTUNG.md and provenance.json. Publish a dedicated downloads/kollo-delfi.zip and include the example in kollo-examples.zip and kollo-student-kit.zip. Do not advertise a deck.kollo.json or native editable PPTX for this video showcase. The generic skill ZIP continues to contain the three fictitious editable examples only.
