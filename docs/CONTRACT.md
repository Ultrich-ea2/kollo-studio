# Kollo implementation contract

New student presentation studio based on the author's bachelor_defense palette and structure. Original personal thesis content is not published. German interface; example academic content explicitly marked as example. Repository source and offline kit in scope; Vercel hosting. All student data remains on device.

Shared model (src/model.ts): Deck {version:1,title:string,author:string,institution:string,date:string,duration:number,theme:{background:string,foreground:string,muted:string,primary:string,secondary:string,font:'Arial'|'Georgia',scale:number,showProgress:boolean},slides:Slide[]}. Slide {id:string,layout:'title'|'section'|'bullets'|'columns'|'process'|'stats'|'quote'|'code'|'image'|'chart'|'references'|'closing',section:string,title:string,subtitle:string,items:string[],body:string,image:string,imageAlt:string,notes:string,source:string,transition:'none'|'fade'|'slide'|'zoom',reveal:boolean,seconds:number}. All fields required. Images only embedded PNG/JPEG/WebP, no remote URLs or SVG. Items format: columns uses two strings; stats/chart use "value | label"; chart numeric nonnegative values.

Exports and UI share a deterministic scene at 1280x720. src/scene.ts exports createScene(slide,deck,index): Scene {background:string,elements:Element[],warnings:string[]}. Elements: Rect {type:'rect',x,y,w,h,fill,stroke?:string,radius?:number,group?:number}, Text {type:'text',x,y,w,h,text,fontSize,color,bold?:boolean,font?:string,align?:'left'|'center'|'right',group?:number}, Image {type:'image',x,y,w,h,src,alt,group?:number}. Text elements contain a single already-wrapped line. Font size pixels. Scene text top coordinates; shared export mapping must account for font baselines. createScene never drops content silently: warn on overflow. svgMarkup(scene): string escapes all text. Visible animations grouped by group integer.

src/model.ts exports defaultDeck (10-12 example slides), layouts Record<layout,string>, createSlide(layout), parseDeck(input:unknown): Deck throws clear German errors, validateDeck(deck): string[], templates Array<{id,name,description,deck}>, cloneDeck(deck):Deck. Import max file 10MB, <=80slides, bounded fields/items/data images, reject invalid schema/prototype keys, preserve valid input exactly (no silent truncation).

src/exports.ts exports async exportPptx(deck,mode:'editable'|'visual'):Promise<Blob>, exportPdf(deck):Promise<Blob>, exportHtml(deck):Promise<Blob>, exportKit(deck):Promise<Blob>, downloadBlob(blob,filename). No automatic download inside exports. Pure standalone HTML plays embedded slides with keyboard navigation/reveals, timer and notes; no network. Editable PPTX uses native scene shapes/text and speaker notes. Visual PPTX and PDF use high-resolution rendered scenes. Disclosure of animation fidelity per format. PPTX basic transition supported via safe OOXML patch if tested, browser-only effects clearly disclosed.

Root owns App.tsx, UI/CSS, state, dependencies, packaging/build/deploy. Core agent owns model.ts, scene.ts, model/scene tests only. Export agent owns exports.ts, export tests only. Documentation agent owns skills/kollo-theme, public/guide.md, README.md, docs/research.md, LICENSE, SECURITY.md only. Avoid unrelated writes. No commits from agents; root commits logical batches.
